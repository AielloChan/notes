# 生活构想

分享家装知识、材料观察与产品体验。

网站：https://aiellochan.github.io/notes/

## 本地运行

需要 Node.js 22 或更新版本，无第三方构建依赖。

```sh
npm test
npm start
```

默认预览地址为 http://localhost:4182/notes/ 。可以用 `PORT=4184 npm start` 更换端口。

## 内容

`site/notes.json` 是正式发布清单，保留源内容的标题、正文、标签与图片顺序。网站图片放在 `site/assets/<内容ID>/`，保持源尺寸和比例，不裁切图文；主要使用质量 90–92 的 WebP，较小原文件沿用原格式。列表封面和缩略图单独生成，阅读与放大使用完整尺寸图片。正文和图片校验值会在构建时验证。仅发布清单列出的图片进入网站构建结果。

截至 2026-10-14，网站包含 279 篇内容、3,461 张配图，其中 6 篇早期文字文章没有留存配图。全部 179 期家居试验和已完成的装修、家庭网络、智能家居、家庭影音内容已导入；影视剧情、电影制作、相机和专业选择等无关主题，以及未开始、废弃和重复旧稿已排除。微水泥在确认照片使用权后纳入发布。

内容按时间排列，首页每次显示 24 篇，可按分类、原文和标签搜索并继续加载。没有配图的文章采用文字阅读布局。原始文件与私有来源快照留在本地，不依赖会过期的素材下载链接。

字体许可证位于 `site/fonts/`。首页材质图为 AI 生成的品牌概念图，页面保留该标识。内容中的品牌产品图片属于对应权利人，不宣称为本团队拍摄。

## 部署

推送到 `main` 后，GitHub Actions 运行发布检查并部署 `dist/` 到 GitHub Pages。默认路径为 `/notes/`；如需根域名部署，使用 `BASE_PATH=/ npm run build`。
